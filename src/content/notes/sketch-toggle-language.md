Sketch 54版本之后会强制使用Mac系统语言

使用Mac终端:

```sh
defaults write com.bohemiancoding.sketch3 AppleLanguages '(en)'
defaults write com.bohemiancoding.sketch3 AppleLanguages '(zh-CN)'
```
